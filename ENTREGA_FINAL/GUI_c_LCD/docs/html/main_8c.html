◆ main()

int main ( int argc,
char * argv[] )

Ponto de entrada do programa.

Configura os handlers de sinal, abre a porta serial, seleciona o modo de operação (via menu ou flag -m) e delega para fsm_run(), debug_run() ou hmi_run(). O handshake com o STM32 é feito aqui para os modos FSM e Debug; no modo HMI é feito internamente em hmi_run(), somente quando o usuário pressiona START.

Parameters
argcQuantidade de argumentos.
argvVetor de argumentos (-p, -b, -c, -t, -m, -h).
Returns
0 em encerramento normal, 1 em erro.
