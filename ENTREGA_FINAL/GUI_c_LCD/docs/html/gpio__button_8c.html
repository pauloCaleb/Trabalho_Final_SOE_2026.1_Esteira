◆ button_was_pressed()

int button_was_pressed ( GpioButton * btn)

Verifica se houve um pressionamento válido desde a última chamada.

Parameters
btnContexto retornado por button_open().
Returns
1 se um press com debounce foi detectado, 0 caso contrário.

Deve ser chamada periodicamente (polling). Detecta borda de descida (1→0) e só reporta o evento após 'debounce_ms' estáveis em nível baixo. Cada pressionamento é reportado uma única vez, independentemente de quanto tempo o botão permaneça pressionado.

Parameters
btnContexto retornado por button_open().
Returns
1 se um pressionamento válido foi detectado, 0 caso contrário.
