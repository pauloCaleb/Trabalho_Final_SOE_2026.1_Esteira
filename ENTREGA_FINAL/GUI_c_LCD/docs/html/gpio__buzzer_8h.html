GpioBuzzer * buzzer_open ( const char * chip_name,
unsigned int line_offset )

Abre e configura uma linha GPIO como saída para o buzzer.

Reserva a linha no chip indicado como saída, já iniciando em nível baixo (buzzer desligado).

Parameters
chip_nameNome do chip GPIO (ex: "gpiochip0").
line_offsetNúmero do pino GPIO (ex: 23 para GPIO23).
Returns
Ponteiro para o contexto em sucesso, NULL em erro.
