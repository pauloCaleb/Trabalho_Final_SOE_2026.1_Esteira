int handshake_poll ( int fd)

Verifica, sem bloquear além do timeout interno de leitura, se o STM32 já respondeu ao handshake iniciado por handshake_send_ready().

Verifica, sem bloquear (além do timeout interno de leitura), se o STM32 já respondeu ao handshake.

Parameters
fdDescritor da porta serial.
Returns
1 se SYS_INIT chegou, -1 se CMD_ERR, 0 caso contrário.

Verifica, sem bloquear além do timeout interno de leitura, se o STM32 já respondeu ao handshake iniciado por handshake_send_ready().

Deve ser chamada repetidamente (polling) depois de handshake_send_ready(). Cada chamada tenta ler um byte da UART com um timeout curto interno (~100 ms) e alimenta o parser – frames que não sejam a resposta do handshake são descartados silenciosamente.

Parameters
fdDescritor da porta serial.
Returns
1 se SYS_INIT (handshake completo) chegou, -1 se o STM32 respondeu CMD_ERR, 0 se nada de conclusivo chegou ainda (chamador deve continuar chamando em loop).

◆ handshake_send_ready()

void handshake_send_ready ( int fd)

Envia SYS_RDY ao STM32 sem aguardar resposta.

Envia SYS_RDY ao STM32 sem aguardar resposta (não bloqueante).

Parameters
fdDescritor da porta serial.

Envia SYS_RDY ao STM32 sem aguardar resposta.

Primeira metade do handshake, para os casos em que a resposta pode demorar por um motivo fora do controle do Raspberry Pi – ex.: o firmware só envia SYS_INIT espontaneamente quando os sensores da esteira ficam livres, o que pode acontecer bem depois deste envio. Use handshake_poll() repetidamente em seguida para verificar a chegada da resposta sem travar num timeout fixo.

Parameters
fdDescritor da porta serial.

◆ protocol_parse_byte()

int protocol_parse_byte ( uint8_t byte,
RxFrame * out )

Alimenta o parser RX com um byte recebido da UART.

Transições de estado: WAIT_STATUS: aguarda 0x90 (CMD_OK) ou 0x91 (CMD_ERR). 0x91 entrega o frame imediatamente (1 byte). WAIT_CMD: guarda o comando; se for SENS_STATUS_MSG (0x55), avança para WAIT_DATA; caso contrário entrega o frame (2 bytes). WAIT_DATA: lê o byte extra e entrega o frame (3 bytes).

Bytes fora de qualquer padrão esperado são descartados com log de erro.

Parameters
byteByte recebido da porta serial.
outPreenchido quando um frame completo é detectado.
Returns
1 se frame completo, 0 se ainda incompleto.

Máquina de 3 estados (WAIT_STATUS → WAIT_CMD → WAIT_DATA) que espelha o parser do firmware. O estado é mantido entre chamadas em variáveis estáticas internas — não é reentrante.

Parameters
byteByte recebido da porta serial.
outPreenchido quando um frame completo é detectado.
Returns
1 quando o frame está completo e *out foi preenchido; 0 enquanto ainda aguarda mais bytes.
