◆ fsm_run()

void fsm_run ( int fd,
int cam_index,
int qr_timeout )

Executa o loop do modo FSM (operação autônoma).

Parameters
fdDescritor da porta serial.
cam_indexÍndice da câmera (0 = /dev/video0).
qr_timeoutTimeout para leitura do QR em ms (0 = sem limite).

Sobe a thread RX antes de inicializar a câmera (evita perder eventos do STM32 durante a abertura do dispositivo de vídeo, que pode levar ~2 s). Em seguida percorre a máquina de estados até g_interrupted ser setado por SIGINT/SIGTERM.

A desinicialização do STM32 (SW_RESET) não é feita aqui; main.c chama deinit_stm32() após o retorno desta função.

Parameters
fdDescritor da porta serial.
cam_indexÍndice da câmera (0 = /dev/video0).
qr_timeoutTimeout para leitura do QR em ms (0 = sem limite).

◆ rx_thread()

void * rx_thread ( void * arg)
static

Thread de recepção UART do modo FSM.

Roda em background, lendo byte a byte com timeout curto e alimentando o parser de protocolo. Ao montar um frame válido, armazena o comando em ctx->rx_event (sob mutex) para o loop principal consumir.

Parameters
argPonteiro para FsmCtx.
Returns
NULL (API pthread).
