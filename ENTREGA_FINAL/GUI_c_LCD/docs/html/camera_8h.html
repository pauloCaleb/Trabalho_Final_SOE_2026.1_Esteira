◆ camera_read_qr()

CamResult camera_read_qr ( int timeout_ms)

Captura frames em loop tentando ler um QR code com rota válida.

Converte cada frame para escala de cinza e passa ao ZBar. Ao detectar um símbolo, extrai o byte de destino do texto decodificado (campo "Destino:" ou token hex avulso).

Parameters
timeout_msTempo máximo em ms (0 = aguarda indefinidamente).
Returns
CAM_ROUTE_A, CAM_ROUTE_B, CAM_TIMEOUT ou CAM_ERROR.
