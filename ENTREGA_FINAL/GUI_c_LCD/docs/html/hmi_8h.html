void hmi_run ( int fd,
int cam_index,
int qr_timeout )

Executa o loop do modo HMI (display + botões + buzzer).

Executa o loop do modo HMI (display + botões).

Inicializa o LCD, os botões GPIO e o buzzer, exibe a tela de espera e aguarda START. Ao pressionar START, inicializa a câmera, executa o handshake e entra na operação autônoma com saída no display. STOP retorna à tela de espera; g_interrupted encerra definitivamente o modo e limpa o display com uma mensagem final.

Parameters
fdDescritor da porta serial.
cam_indexÍndice da câmera (0 = /dev/video0).
qr_timeoutTimeout para leitura do QR em ms (0 = sem limite).

Executa o loop do modo HMI (display + botões + buzzer).

Ao pressionar START na tela de espera, a câmera é inicializada primeiro; só depois dela estar pronta o handshake com o STM32 é disparado. Isso garante que a operação autônoma só comece quando todo o hardware necessário – câmera incluída – já estiver de pé.
