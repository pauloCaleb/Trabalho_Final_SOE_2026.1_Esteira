◆ parse_qr_text()

uint8_t parse_qr_text ( const char * text)
static

Extrai o byte de destino de rota a partir do texto de um QR code.

Tenta duas estratégias em ordem:

  1. Procura o campo "Destino:" (ou "destino:") e lê o hex seguinte. Aceita formato "0xAADA" (byte alto = START_FRAME) ou "0xDA" isolado.
  2. Fallback: varre o texto inteiro procurando tokens "0xXX" válidos.
Parameters
textTexto decodificado do QR (terminado em NUL). Pode ser NULL.
Returns
ROUTE_A_SEND (0xDA), ROUTE_B_SEND (0xDB) ou 0 se não encontrado.
