◆ debug_run()

void debug_run ( int fd)

Executa o loop do modo Debug (controle manual).

Parameters
fdDescritor da porta serial.

Sobe uma thread RX para monitorar eventos e telemetria em paralelo, e apresenta um menu interativo no terminal. Bloqueia até 'q' ser pressionado ou g_interrupted ser setado por SIGINT/SIGTERM.

A desinicialização do STM32 (SW_RESET) não é feita aqui; main.c chama deinit_stm32() após o retorno desta função.

Parameters
fdDescritor da porta serial.
